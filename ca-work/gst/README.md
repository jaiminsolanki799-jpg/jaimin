# gst

Indirect tax work.

| Folder | Scope |
| --- | --- |
| `registration/` | New registration, amendment, and cancellation formats |
| `returns/` | GSTR-1 and GSTR-3B preparation workings |
| `annual-return/` | GSTR-9 and GSTR-9C |
| `reconciliation/` | GSTR-2A/2B versus books, and turnover versus books |
| `notices/` | Departmental notices and reply drafts |

Reconciliation is the work most worth templating — a reusable format saves
hours every month.
