# audit

Audit programmes, checklists, and formats, split by engagement type.

| Folder | Scope |
| --- | --- |
| `statutory-audit/` | Audit under the Companies Act — planning, programme, and reporting formats |
| `tax-audit/` | Section 44AB work — Form 3CA/3CB and the 3CD annexure |
| `internal-audit/` | Internal audit scope notes, process walkthroughs, and observation formats |
| `bank-audit/` | Statutory branch audit, concurrent audit, and LFAR formats |
| `stock-audit/` | Physical verification programmes and stock count sheets |

Keep only blank formats and generic programmes here. Anything carrying client
figures belongs in `../clients/`, which is git-ignored.
