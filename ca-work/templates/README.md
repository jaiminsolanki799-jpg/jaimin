# templates

Blank formats, reused across engagements. Nothing here should carry a client
name or a figure.

| Folder | Scope |
| --- | --- |
| `engagement-letters/` | Engagement letters by service type |
| `representation-letters/` | Management representation letters |
| `working-papers/` | Working paper formats, lead schedules, and index sheets |

When a template is revised, note what changed and when at the top of the file
so an older copy is recognisable.
