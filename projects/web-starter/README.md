# web-starter

A static single-page scaffold with no build step and no dependencies. Open it in
a browser and start editing.

## Layout

```
web-starter/
├── README.md
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js
```

## Run

Open `index.html` directly in a browser, or serve the folder so relative paths
behave the same way they would in production:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
